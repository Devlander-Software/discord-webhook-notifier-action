Quick Start

Get up and running in minutes with our simple setup process

  • 1

    Create Discord Webhook

    Go to your Discord server settings and create a webhook

  • 2

    Add to GitHub Secrets

    Add your webhook URL to your repository secrets as DISCORD_WEBHOOK

  • 3

    Add to Workflow

    Add the action to your GitHub Actions workflow file

- name: Notify Discord
  uses: Devlander-Software/discord-webhook-notifier-action@v1.1.0
  if: always()
  with:
    webhook: ${{ secrets.DISCORD_WEBHOOK }}
    status: ${{ job.status }}
    workflow: ${{ github.workflow }}
    job: ${{ github.job }}
    repo: ${{ github.repository }}
    branch: ${{ github.ref_name }}
    commit: ${{ github.sha }}
    actor: ${{ github.actor }}
    run_url: ${{ github.server_url }}/${{ github.repository }}/actions/runs/${{ github.run_id }}
